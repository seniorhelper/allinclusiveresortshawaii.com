Privacy policy

Short version: we don't collect personal information on this site.

Updated November 10, 2026

What we collect

This site has no sign-up forms, no accounts and no advertising trackers, and it sets no cookies. The trip cost estimator runs entirely in your browser. The numbers you type are not saved or sent anywhere.

Hosting

The site is hosted on GitHub Pages. Like any web host, GitHub may log technical data such as IP addresses to operate and secure the service. See GitHub's privacy statement for details.

Links to other sites

We link to official sources such as Hawaii government pages and the cruise line. Those sites have their own privacy policies.

Changes

If we add analytics or advertising in the future, we'll update this page first and describe exactly what is collected.

Questions? See the About page for how to reach us.
